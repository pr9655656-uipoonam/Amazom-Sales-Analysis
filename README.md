# Amazon Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing Amazon sales data using Python to identify important sales trends, product performance, and useful business insights.

The dataset was cleaned, analyzed, and visualized using Python libraries.

## 🎯 Objectives

- Analyze Amazon sales data
- Understand sales trends and patterns
- Identify top-performing products
- Analyze product categories
- Find useful business insights
- Create meaningful data visualizations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset

The project uses an Amazon Sales Dataset containing information related to products, orders, sales, categories, and other relevant attributes.

## 🔍 Data Analysis

The following steps were performed:

1. Imported the dataset
2. Explored the dataset
3. Checked missing values
4. Cleaned and prepared the data
5. Performed exploratory data analysis (EDA)
6. Analyzed sales and product performance
7. Created visualizations
8. Generated key business insights

## 📊 Visualizations

The project includes different visualizations such as:

- Bar Charts
- Line Charts
- Histograms
- Pie Charts
- Distribution Analysis
- Product/Category-wise Analysis

## 💡 Key Insights

- Identified the best-performing products and categories.
- Analyzed sales patterns and trends.
- Compared product/category performance.
- Used visualizations to understand the dataset more effectively.
- Generated actionable insights from the sales data.

## 🚀 How to Run the Project

1. Clone this repository.
2. Download the Amazon Sales Dataset.
3. Open the Jupyter Notebook.
4. Install the required Python libraries if needed.
5. Run the notebook cells step by step.
